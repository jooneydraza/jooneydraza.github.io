Why did my ebook's spacing and indents break on Kindle?

Updated 31 October 2026 · 2 min read · Jooneyd Raza

Short answer

Kindle ebooks are reflowable, so tabs, repeated spaces, blank lines and fixed font sizes from a Word file collapse or get overridden when the reader changes the text size. Set indents and spacing with paragraph styles, add a page break after each chapter, and check a clean EPUB, DOCX or KPF file in Kindle Previewer.

Why Word layout breaks on Kindle

A Kindle ebook has no fixed pages. The reader picks the font, the text size and the line spacing, and the text reflows to fit. Tabs, repeated spaces and blank lines used for layout in Word don't survive that.

Kindle Create is one way to fix it, but not the only one. A clean EPUB or DOCX built with paragraph styles works too.

KDP's rules for reflowable text

  • Body text uses the default font size (1em) and line height.
  • No forced typeface for body text.
  • Avoid double-spacing between paragraphs.
  • No imposed margins and no non-breaking spaces between words in body text.
  • Indents set by paragraph style, no more than 4 ems.
  • A page break after each chapter.

Which files to upload

KDP recommends EPUB, DOCX or KPF, the Kindle Create format. MOBI ended on Aug 1, 2021 for reflowable books and on Mar 18, 2025 for fixed layout. Check the file in Kindle Previewer before you publish.

Picture books and other stores

Picture books, comics and cookbooks need fixed layout instead. For kids' books, Kindle Create imports PDF, PNG or JPEG pages with the text already placed in the images. IngramSpark ebooks require EPUB 3.0, with an RGB JPG cover at least 1,873 px on the longest side.
